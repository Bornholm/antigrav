# Politique de confidentialité

*English version below.*

Soundwave ne collecte, ne stocke sur un serveur et ne transmet à personne aucune donnée personnelle. Le jeu n'a ni compte, ni publicité, ni outil de mesure d'audience, ni rapport de plantage envoyé à un tiers.

## Ce qui reste sur l'appareil

Le jeu enregistre dans son dossier privé vos réglages, vos meilleurs scores, votre pseudo et les morceaux que vous avez ajoutés. Ces fichiers ne quittent pas l'appareil, sauf par la sauvegarde d'Android si vous l'avez activée. Désinstaller le jeu les supprime.

## Multijoueur en Wi-Fi local

Une partie à plusieurs passe par le réseau Wi-Fi local, directement entre les appareils des joueurs, sans serveur. Les appareils de la partie s'échangent le pseudo de chaque joueur, les données de la course et le morceau choisi par l'hôte. Rien ne sort du réseau local.

C'est la raison des deux autorisations demandées : l'accès au réseau, et la réception des annonces de partie diffusées sur le Wi-Fi.

## Recherche de mise à jour, versions Windows et Linux

Au démarrage, les versions Windows et Linux demandent à GitHub le numéro de la dernière version publiée, par une requête à `api.github.com`. Elles n'envoient rien d'autre que cette demande : ni pseudo, ni réglage, ni identifiant. Comme pour toute connexion, GitHub voit l'adresse IP de l'ordinateur, selon sa propre [politique de confidentialité](https://docs.github.com/fr/site-policy/privacy-policies/github-general-privacy-statement). Le réglage MISES À JOUR de l'écran Options coupe cette recherche. La version Android ne la fait pas.

## Vos fichiers de musique

Un morceau que vous ajoutez est lu et analysé sur l'appareil. Le jeu ne l'envoie nulle part, sauf aux autres joueurs d'une partie en Wi-Fi local quand vous êtes l'hôte et que vous le choisissez.

## Contact

Pour toute question, ouvrir un ticket sur https://github.com/Bornholm/soundwave/issues

# Privacy policy

Soundwave does not collect, store on a server or share any personal data. The game has no account, no ads, no analytics and no crash reporting sent to a third party.

## What stays on the device

The game saves your settings, your best scores, your nickname and the songs you added in its private folder. These files never leave the device, except through Android's own backup if you turned it on. Uninstalling the game deletes them.

## Local Wi-Fi multiplayer

A multiplayer game runs over the local Wi-Fi network, directly between the players' devices, with no server. The devices in the game exchange each player's nickname, the race data and the song picked by the host. Nothing leaves the local network.

This is why the game asks for two permissions: network access, and receiving the game announcements broadcast over Wi-Fi.

## Update check, Windows and Linux versions

At startup, the Windows and Linux versions ask GitHub for the number of the latest release, with one request to `api.github.com`. They send nothing but that request: no nickname, no setting, no identifier. As with any connection, GitHub sees the computer's IP address, under its own [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The UPDATES setting in the Options screen turns this check off. The Android version does not make it.

## Your music files

A song you add is read and analysed on the device. The game sends it nowhere, except to the other players of a local Wi-Fi game when you are the host and you pick it.
